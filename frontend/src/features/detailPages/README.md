# S5 Detail Pages

This folder contains the first S5 detail-page pattern proof.

S5-2A does not extract real dashboard content, migrate routing, add workspaces, or activate the navigation skeleton. The preview page exists to define the expected detail-page structure before Results or Dataset detail pages are implemented.

## Required Detail-Page Elements

- page title
- source context
- back target
- key facts
- primary body
- related actions
- preserved context note

## Back Behavior

Back behavior is documented only in this phase. A future routed detail page should return to the originating surface without resetting dataset, session, workbook, mode, filters, pagination, exports, result state, or expanded panels.

## Current Status

No visible entry point is wired in S5-2A. Real Results and Dataset detail pages come later.
